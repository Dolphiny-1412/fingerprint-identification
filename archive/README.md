# Archive: original development workspaces

Earlier, separate workspaces from the first version of this project (written by me, Youssof Ahmed). The current code is in `../src/`. Nothing here is needed to run the app and none of it is maintained.

The project was set up as a team project with one workspace per module. The folder names below keep that original split, and they are only labels (the "member" letters in them do not mean different authors).

| Folder in `original-workspaces/` | What it holds |
|---|---|
| `member-b-classifier-matcher` | First pattern classifier and matcher |
| `member-c-minutiae-ai` | Minutiae detection, AI experiments and many development notes (the notes make claims about "production success" that were never backed by a measured evaluation) |
| `member-d-matching-db` | Matching and database prototype |
| `member-e-ai-assistant` | AI assistant prototype |
| `integrated-toolkit` | First attempt at joining the modules, with Windows paths from the original machine |
| `mahe` | Early module folders |

Treat any accuracy or success claim in these files as unverified.
