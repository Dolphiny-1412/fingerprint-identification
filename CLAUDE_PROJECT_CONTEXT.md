**Quick orientation:**
- Production code lives in `src/` only
- Main UI: `src/ui/app_modern.py`
- Core modules: `src/core/` (classifier, minutiae_detector, fingerprint_matcher, ai_assistant)
- `Fingerprint B/` through `Fingerprint E/` and `M.A.H.E/` are per-student prototypes — do not edit these for production fixes
- See `README.md` for setup and run instructions
